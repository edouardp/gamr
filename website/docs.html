Keybindings

KeyAction
↑/↓Navigate files
j/kNavigate (tree) or scroll (preview)
→Expand directory
←Collapse directory or go to parent
spaceToggle expand/collapse or page down
vCycle view mode (tree → flat name → flat path)
dCycle diff mode (full → gutter → unified)
sSide-by-side diff popup
J/nNext diff hunk
K/NPrevious diff hunk
oCycle diff overview style
gToggle git modified filter
fToggle follow mode
ctrl+fFocus search input
bToggle blame columns
1–7Toggle individual columns
OOpen file in default app
tabSwitch focus (tree ↔ preview)
ctrl+pCommand palette
?Show help
qQuit (saves state)

View Modes

Tree

Hierarchical directory tree with expand/collapse. Desktop-style ←/→ navigation.

Flat (Name)

All files in a flat list sorted by filename. Great for fuzzy searching.

Flat (Path)

Flat list showing relative paths. Useful for seeing full file locations.

Diff Modes

Full File

Complete syntax-highlighted file with inline +/- markers and colored backgrounds.

Gutter

Full file with change indicators in the gutter — minimal but informative.

Unified

Traditional unified diff format showing only changed lines with context.

Project Structure
src/gamr/
├── app.py                  # Textual app, keybindings
├── commands.py             # Command palette
├── models.py               # FileEntry, GitStatus, etc.
├── state.py                # Persistent state
├── preferences.py          # User preferences
├── preview.py              # Preview orchestration
├── services/
│   ├── diff_parser.py      # Unified diff → DiffData
│   ├── file_scanner.py     # File watching
│   ├── file_index.py       # Scanner + git → FileEntry
│   ├── git_provider.py     # Dulwich git interface
│   ├── filter.py           # Fuzzy & status filtering
│   └── icons.py            # Icon loading
└── widgets/
    ├── file_tree_table.py  # DataTable with tree
    ├── tree_data.py        # Tree building & sorting
    ├── toolbar.py          # Logo + search
    ├── preview_pane.py     # Syntax preview + diffs
    ├── side_by_side.py     # Side-by-side modal
    ├── help.py             # Help modal
    └── split.py            # Resizable split
