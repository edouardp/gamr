# Changelog

## 0.1.0 (unreleased)

Initial release.

- Git-aware file browser TUI with Textual
- Live file watching (watchdog + polling fallback)
- Pure Python git via Dulwich (no git binary required)
- Four diff modes: full, gutter, unified, plain preview
- Diff overview bar (line and braille styles)
- Three view modes: tree, flat name, flat path
- Fuzzy search with RapidFuzz
- Git status filtering
- Syntax-highlighted preview with Monokai theme
- Gradient colors for size and mtime columns
- lsd icons.yaml support
- Resizable split pane
- Column sorting via header click
- State persistence to `.gamrstate`
- Desktop-style keyboard navigation
